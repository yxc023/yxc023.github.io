# Change: 现代化网站样式与字体优化

## Why
当前博客的样式存在以下问题，影响用户体验：
1. 字体大小偏小，基础字体为Bootstrap默认大小，阅读体验不佳
2. 行高设置不当，中文阅读舒适度有待提升
3. 字体堆栈缺乏现代化配置，未充分利用系统字体
4. 段落间距和排版密度需要优化
5. 代码块样式过时，不符合现代开发者阅读习惯
6. 移动端响应式排版需要改进

## What Changes
- 更新 `build/gitPublish/css/base.css` 和相关样式文件
- 调整基础字体大小从 ~14-15px 提升到 16-18px
- 优化行高从 1.0-1.4 提升到 1.6-1.8，提升中文阅读体验
- 改进字体堆栈，使用现代化系统字体栈
- 优化段落、标题、代码块的样式
- 增强移动端响应式设计
- 提升整体信息可读性和视觉舒适度

## Impact
- 受影响的文件：
  - `build/gitPublish/css/base.css` - 主要样式文件
  - `build/gitPublish/css/adoc-golo.css` - AsciiDoc样式
  - 可能需要更新 `src/jbake/assets/css/` 中的源文件
- 受影响的页面：所有页面（首页、文章页、归档页等）
- 性能影响：样式文件大小略有增加，但提升用户体验
- 向后兼容：样式调整是增强性的，不破坏现有功能

## Design Goals
1. **可读性优先**：优化字体大小、行高、字间距
2. **现代化外观**：符合2024-2025年网站设计趋势
3. **中文友好**：特别优化中文字体显示和阅读体验
4. **移动优先**：确保移动端良好显示效果
5. **开发者友好**：改进代码块和技术内容的可读性
