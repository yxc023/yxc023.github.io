3. **opencode 桌面端 2.2.0 出现一批彼此独立但都指向「新特性未收尾」的故障，其中三个可量化。** [#60050](https://github.com/anomalyco/opencode/issues/60050)：`/api/experimental/generate` 在 12.8 KB prompt 上从 2.1.4 的 18–42 s 变成 **200–223 s**（两次超过 300 s），同一模型直连 provider 只需 2.5 s——**慢在宿主侧，不在模型**；[#60017](https://github.com/anomalyco/opencode/issues/60017)：v2 二进制在 x86-64-v1 CPU（Intel Core 2 Quad Q9400）上启动即 **SIGILL**，因为 Bun 的 baseline 构建仍有 Nehalem 硬底线（SSE4.2 + POPCNT）；[#60059](https://github.com/anomalyco/opencode/issues/60059)：桌面每次重连都会让常驻 service 再拉起一整套本地 MCP server 子进程且不回收，两次重启后两代共 3 个 MCP server 同时存活（约 440 MB 进程），子进程被杀后也不重启。此外 [#60014](https://github.com/anomalyco/opencode/issues/60014)（Code Mode 目录漏掉内置工具，`tools.shell` 报 Unknown tool shell）、[#60030](https://github.com/anomalyco/opencode/issues/60030)（后台 shell 变成杀不掉的僵尸条目且跨重启存活）、[#60004](https://github.com/anomalyco/opencode/issues/60004)（`plugin.list()` 无 location 时把 `$HOME` 变成永久 location，启动所有全局插件）、[#60005](https://github.com/anomalyco/opencode/issues/60005)（插件 server 重启后卡在 loading，事件流反复请求 `http://127.0.0.1:0`）全部指向同一个来源：**v2.2.0 的桌面插件体系（[#55246](https://github.com/anomalyco/opencode/pull/55246) 起）在本期被至少 6 个 issue 指名。**
