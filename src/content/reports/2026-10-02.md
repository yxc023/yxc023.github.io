## 跨项目观察

- **"stable 1.0" 节点对比**：earendil-works/pi v1.0.0 与 ACP schema-v2.0.0-alpha.7 都打"协议级稳定 / v2 alpha"，但**pi 的 v1 是主版本 stable**，**ACP 的 v2 仍是 alpha**——同一个生态对"ready for production" 有截然不同的判断：纯 agent 项目（pi）可以稳定到 v1.0；协议项目（ACP）因为生态绑定者多，必须维持 alpha 状态以保留调整空间。
- **"agent runtime 持久化" 一致收敛**：pi-durable（async SQLite + vacation planner demo）、hindsight（bank alias / clone / rename）、orange 数据（namespaced session identity headers）三方各自往"agent 可挂起 / 可重建"方向走；本期没有看到颠覆性新方法，全部是细节加固。
- **Radius 模型路由 / MCP 一体化** 已进入 v1.0：pi v1.0.0 `/login` 顶部直接显示 Sign in with Radius 并一键配 MCP server（`auth: { provider: "radius" }`），让 Radius 既是一个 provider 也是一个 MCP server host——这是一种"模型路由 + MCP 入口"在工具链上的合并方向。
- **durable + system theme + quiet startup 三件套**共同成为 v1.0 "开箱即用"体验：fullscreen 默认 + 安静启动 + 持久化 harness，这三个能力的合并是 pi 的"v1.0 UX 哲学"——少操作、可恢复、视觉简洁。
- **macOS 27+ 公证链条**从 opencode 蔓延到所有 agent CLI 二进制（pi v1.0.0 修 Apple Terminal logo 渲染、CLI 走 Apple Developer 签名），这是平台级边界对所有 agent CLI 的同步收口。
- **codemode 现在是 "chat + classify + generate images" 三 API 的稳定形态**（pi v1.0.0）：预测 / embed 极可能沿用同一形态，codemode 正成为 pi 的"脚本化多模型调用平台"。
- **Jev（TypeSafe System One 模型）成为跨项目流通的"轻量打分原语"**：hindsight 把 Jev 当 reranker，pi 把 Jev 当 virtual model 路由，"typed answer + calibrated probability" 这个新原语正在被两个项目采纳。
- **subagent 在三个项目同步进入 schema**：ACP v1.10.0 unstable subagent schema + pi-web 的 subagent 一致性收紧 + pi 的 go() / owner / child tasks；三方对齐到同一抽象，subagent 即将从"项目特性"升级为"协议级原语"。
- **Hindsight 与 Hermes 解耦**（PR #4879）：plugin 仓库从 Hermes core 移到 Hindsight 仓库，由 Hindsight 团队维护；**Hindsight 现在是独立的 agent memory 协议层**，可被多 agent runtime 集成，不再依赖 Hermes core 节奏。
