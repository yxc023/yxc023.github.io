**近 N 周 release 重点：**

- **v1.0.4**（2026-10-05）— `--tools` glob + `--no-mcp` + codemode image block
  - **`--tools` / `--exclude-tools` 支持 glob**：例如 `--tools read,codemode,'mcp__radius__*'` 保留单家 MCP 的工具；`--tools` 默认不再移除 MCP 工具（除非显式 `mcp__` 前缀），`--no-mcp` 单次关闭 MCP。修 #10143 / #10249 / #10251 / #10343 / #10379 / #10444 等。
  - **Codemode `read()` 解析 image block**：`tools.read()` 在 image 文件上现在返回 image block（带 note），`image()` 渲染——codemode 终于能"读图"。fix #10251。
  - **MCP OAuth CIMD `application_type=native`**：OpenID Connect 授权服务器对未声明 `application_type` 的注册按 web client 处理，从而拒绝 loopback redirect URI；现在按 redirect_uris 派生——loopback host / custom scheme 视为 native，否则 web——修 #10493 / MCP SEP-837。
  - **MCP 连接关闭 race fix**：`close()` 在连接中 abort per-connection signal（取消 in-flight client + retry wait + 等 connect 收敛后再返回），修 #10249。
  - **隐藏工具不污染 system prompt**：声明规则和 skills hint 跟随"active minus hiddenDeclarations"；reader 被 hide 时 skills hint 不再点名；codemode 把每个 tool 的 prompt guidelines 跟着 declaration 一起出现，新增 `ToolLoadout.getPromptGuidelines()`，修 #10343。
  - **Bedrock HTTP/2 stream cancel 重试**：stalled HTTP/2 连接会让 Bedrock 请求挂到 SDK 的 5 分钟 session timeout（`ERR_HTTP2_STREAM_CANCEL`），现在未发送的请求自动重试，修 #10379。
  - **Codemode 内置对象冻结**：`Array.prototype.toJSON = ...` 之类的 patch 不再有效；worker payload 在 host 侧校验，畸形 payload 走 sandbox error 而非 host crash，修 #10444。
  - **语法高亮 multiline 修**：`#10356` 修 fenced code block 多行字符串 / 注释的第一行之后颜色丢失。
  - 完整 release notes: https://github.com/earendil-works/pi/releases/tag/v1.0.4

- **`b223082` 把 codemode 内置对象 freeze**：之前 codemode script 能 patch `Array.prototype.toJSON = ...` 让整个 worker 卡死 / crash——是个非常具体的沙箱边界。现在 freeze built-ins + read-only built-in globals（保留 instance override 走 accessor），host 侧也校验 worker payload，是 codemode 从"JS 沙箱"升级到"JS 沙箱 + host 验证"的关键一步；与 opencode v2 #53040（preserve subagent text block boundaries）都是 "agent host–subagent 边界" 在加固。
