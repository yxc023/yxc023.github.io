## 本期速览

1. **opencode v2.2.0 终于发版了，而这次发版本身就是上一期「发版闸门收紧」的第一个真实样本。** 2026-10-27 09:04 发布，npm `@opencode/cli` latest 从 2.1.4 变为 **2.2.0**（此前连续 4 天未动）。release notes 有 4 条 Breaking Changes，其中两条是纯移除：**OpenCode GitHub Action 不再发布**（[#59032](https://github.com/anomalyco/opencode/pull/59032)），以及 `@opencode/ai` 包根改成 Promise API、Effect API 移到 `@opencode/ai/effect`、通配子路径导出被显式列表取代（[#58847](https://github.com/anomalyco/opencode/pull/58847) / [#59183](https://github.com/anomalyco/opencode/pull/59183)）；第三条是 TUI 插件硬性要求 **OpenTUI 0.7**（[#59295](https://github.com/anomalyco/opencode/pull/59295)）。亮点是实验性的 **Desktop GUI 插件**（[#55246](https://github.com/anomalyco/opencode/pull/55246) / [#59469](https://github.com/anomalyco/opencode/pull/59469) / [#59489](https://github.com/anomalyco/opencode/pull/59489)）与**实验性的 image / decision 生成 API**（[#59190](https://github.com/anomalyco/opencode/pull/59190)）。

2. **「双发布线」从权宜之计变成了显式设计：GitHub 的 Latest release 仍指向 v1.19.4，npm latest 却是 2.2.0。** 维护者 Hona 的 PR [#59529](https://github.com/anomalyco/opencode/pull/59529) 标题直接写着「restore desktop app-update.yml and keep V1 as the GitHub Latest release」，并解释了原因：`pack.ts` 用 `electron-builder --dir` 构建，app-builder-lib 只为 `dmg`/`zip`/`nsis` 写 `resources/app-update.yml`，而 updater 从不调 `setFeedURL`——**任何更新到缺失该文件的构建的用户，将永远无法再自动更新**。同一 PR 还列出两个发布阻塞项：#59529 修回 `app-update.yml`，#59665 让 v1 在没有 `OPENCODE_APP_ID`/`OPENCODE_APP_SECRET` 的情况下也能发版（「本周的 CI 收紧删掉了这两个密钥，绑定了 npm trusted publishing，于是每一个 v1 `publish.yml` 运行都失败」）。**新流水线在第一次稳定运行前就被自己的产物格式卡住了。**

3. **opencode 本期出现三个独立的「费用算错」报告，且方向互相矛盾——一次高估 10⁶ 倍、一次低估 6 倍、一次记成 0。** [#59677](https://github.com/anomalyco/opencode/issues/59677) 指出 `cortecs/glm-5.2` 会话侧栏显示 $8,386,053，原因是把 catalog 的 `cost[].input`（schema 明确写的是 **USD per million tokens**）当成 per-token；[#59671](https://github.com/anomalyco/opencode/issues/59671) 指出 GitHub Copilot 的 `claude-haiku-5.5` 存在 ≤100K / >100K 两档定价而长上下文档从未被应用，且 380 万 cache-write token 被按 $0 计，导致 25 小时会话显示 $1.56、实际约 $9.3–10.2；[#59627](https://github.com/anomalyco/opencode/issues/59627) / [#59634](https://github.com/anomalyco/opencode/issues/59634) 则报告 2.2.0 对 opencode-go 模型把 session cost 记成 0。**同一个面板上同时存在 10⁶ 倍高估、6 倍低估与归零三种故障——「成本显示」这个功能目前不可作为事实依据。**

5. **opencode 本期最重的一块基础设施改动来自外部：jlongster 把 `opencode-pty` 整体并入 monorepo（+12,790 行 / 58 文件，[#59694](https://github.com/anomalyco/opencode/pull/59694)），并跟了 7 个后续 PR。** 方向是 daemon 化与去轮询：支持私有 Unix socket 目录（`OPENCODE_PTY_SOCKET_DIR`，[#59697](https://github.com/anomalyco/opencode/pull/59697)）、用阻塞订阅替代轮询（[#59698](https://github.com/anomalyco/opencode/pull/59698)，其上游 stack 计划彻底去掉 daemon 的空闲唤醒）、从 monorepo 发布（[#59695](https://github.com/anomalyco/opencode/pull/59695)）。同期 rekram1-node 把 Code Mode 从「每次异步调用一个 fiber」改成「一个 job 队列」（+3,664/−2,995，35 文件，[#57976](https://github.com/anomalyco/opencode/pull/57976)）。**两个方向都是「把并发从每请求一个执行单元，改成统一的调度器」。**

6. **pi 本期把「watch / observer / report」三套词汇合并成一套，这是 durable + chord 连续第三期的同一主题。** commit `5f312da`「feat(chord,durable): failures are watch calls; one vocabulary for watches, observers and reports」把 Chord 的 watch 监听器参数改成带 tag 的调用对象 `{ kind: "value", value, ops, retired }` 或 `{ kind: "failed", error }`，`WatchEnd` 改用 `kind` 标记、context 被 abort 时结束原因从 `cancelled` 改为 `aborted`，Durable 侧 `onReport` 带 `report.kind`、`session_failed` 改名 `storage_failed`、`subscribeCommits` 改名 `observeCommits`。配套 commit `f3255de` 引入 windowed conversation view、`ConversationTranscript` 与 `runFailure`，并**移除 `watchEvents()` 及其 5 个事件类型**（见 [#11327](https://github.com/earendil-works/pi/issues/11327)）。**渲染器不再从事件流里拼状态，改为直接读状态——事件类型不再是每个客户端都必须学会的扩展点。**

7. **pi 的用户侧新发现集中在「缓存与前缀」这一层。** [#11500](https://github.com/earendil-works/pi/issues/11500) 指出 compaction / summarization 请求与实时对话**不共享任何 token 前缀**——每次压缩都在 Anthropic / 本地 vLLM APC 上付一次全量 prefill，作者在 100k+ 上下文的本地端点上实测压缩请求缓存命中为 0；对应的 PR [#11499](https://github.com/earendil-works/pi/pull/11499) 当天就提交了 prefix-preserving summarization。另两条：#11493 报告 Codex 在空闲后缓存全失效（与 persistent-cache 保证矛盾）、#11473 指出 codemode 默认内联完整 schema，13 个工具就能耗尽 3000 token 的 `inlineBudget`，超预算的工具**连名字都不出现**，模型无从知道它存在。**「缓存」正从性能优化变成正确性问题。**
