## 本期速览

- **anomalyco/opencode**: 1.x 最后一个功能型 release 到来了——v1.19.0（10-11）把 `opencode upgrade --major` 和 `/update` 变成通往 OpenCode 2 的唯一通道，并且**取消自动安装更新**；同一版把 PTY 检查改成「先校验 origin 与 ticket，再判断 PTY 是否存在」。升级通道打开的当天，V2 侧就收到一份标为 SECURITY 的报告 #54632：plan mode 在 V2 只是**建议性**而非强制执行——Plan agent 拒绝 `edit`/`write`/`patch`，却对 `shell` 没有任何规则，于是落到默认 allow；`external_directory` 自 #53585 起也默认 allow。维护者 bot 确认这是已知问题并把报告判为 #53955 的重复，修复 PR #54165（10-09 提交）**至今 open 未合**。

- **earendil-works/pi**: durable code mode 在一天内落成 6 个 commit。`sandbox.start()` 让脚本带虚拟时钟与种子随机数**确定性重跑**，每次调用的结果先写 journal 再投递；重跑时 nested call 按 key `c<id>` 重新挂接，journal 缺的调用会被扣住直到 replay 结束，再与历史尝试的 key 对账；divergence、模块版本变化、sandbox 指纹变化、deadline 超时都会终止调用并存下错误。`bench:codemode` 把对比写进了 commit message：1,000 次并行调用 0.82 vs 0.78 ms/call，串行 1.52 vs 1.10 ms/call（每次调用多两个 commit：journal 条目和计数）。

- **earendil-works/pi**: compaction 从「静默失败」改为「显式失败」。89e5c2c 记录的场景是——一次 blocking compaction 失败后，生成仍然照发请求，context 仍高于阻塞阈值，1M 窗口下 996K 的 session **每一轮都拿到空的 length 回答，而界面上看不到任何错误**。现在 compaction 失败/fault/orphan/被中止会让生成以 `model_error (Compaction failed: …)` 结束，`pi.live.compactionFailure` 保留最近一次失败直到产出摘要。15e7bdc 同时修掉一个 1.38M-token 的 summarization 请求：thinking 不该进摘要（replayed thinking 常常根本不在 live context 里，provider 也只返回推理部分的摘要）。

- **earendil-works/pi**: Session 的 document cache 从「进程生命周期」改成「按用量回收」。f44707e 引入 `documentRetentionMs`（默认 10 分钟，0 = 用完即丢，Infinity = 永不淘汰），没有 watch / document state 观察的文档在静默期后从 cache 退场，下次访问重新从 Storage 加载。`bench:document-cache` 测出的量级：5,000 个会话原本常驻 26,000 个文档、每个约 3.8 KB。配套的 cdaf6c2 把图像准备搬进 worker thread，6 兆像素图片从阻塞 event loop 200ms 以上降到 100ms 以内。

- **agentclientprotocol/agent-client-protocol**: v1.25.0 / Rust crate v1.11.0（10-09）把 **session notices 与 session compaction 两条 RFD 同时从 Preview 推到 Completed**，v2.0.0-alpha.8 同步。同一批的 #2333 把「fallback 本身带有含义」的字段从宽容解析改成严格拒绝：v1 `terminal/create` 的 `args`/`env`/`cwd`/`output` 等，之前收到畸形值会静默做成与发送方意图不同的事，现在直接拒。这是对上周「用拒绝换掉默认放行」这条线在协议层的收口。

- **agegr/pi-web**: v0.12.0（10-11）是一版几乎纯性能的 release。流式回复改成按 Markdown 块增量解析（#1176），会话列表接口不再携带每条会话的完整首条消息（大目录 **3.2 MB → 385 KB**），约 300 种 Prism 语言改为按需加载（#1183），工具结果图片由浏览器长期缓存，每次运行结束只重建一次列表。同时把 0.11.0 那个「npm 包内固定密钥可绕过密码」安全修复的余波收干净：指向已删除会话的链接不再回落到项目上一个会话（#1180）、`ctx.reload()` 在生成期间被守卫拒绝（#1173）。
