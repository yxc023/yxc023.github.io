- **subagent 在三个项目同步进入 schema**：ACP v2 unstable 的 subagent `subagent_update`（PR #1992 + RFD）、pi-web 的 subagent profile skill/extension scoping（#955）、pi 主线 `go() / owner / child tasks` + pi-durable 的 durable storage——三方对齐到同一抽象：**subagent 是 agent 内部对象，不是父会话的另一个用户**；opencode 的 `task-parallel`（#47107）把"fan out + join"做成一等公民工具，是这条线上最新的具体能力。
- **codemode 现在是 "chat + classify + generate images" 三 API 的稳定形态**（pi v1.0 + v1.0.1）：codemode 脚本可生成图像、调用分类器、调用 Jev 做 typed answer，未来 predict / embed 极可能沿用同一形态，**codemode 正成为 pi 的"脚本化多模型调用平台"**。
- **生态战争焦点从"能不能做"走向"做得便宜"**：pi v1.0.1 的 cache 命中率优化、codemode 输出上限 16 Mi、prompt token 减 40%、opencode token throughput 包含 provider wait、hindsight streamed export 大 bank 不 OOM——**这些都是"成本真的"工程优化**，意味着 v1 runtime 已经把"跑得起"做到位，开始竞争"跑得便宜"。
- **Figma MCP allowlist 现象**（Clauday 文章）：Figma 的 remote MCP server 只接受 allowlist 上的 client，Pi 不在 list 上——**"开放协议 + 闭门客户端"是 SaaS MCP 的实际形态**，harness 必须要在每个 SaaS 的 allowlist 上有座位才能用其 MCP server，这是 MCP 商业化推进的副作用。
- **Docusaurus / SPA 抓取的实践问题**：hindsight blog（"What Changes Now That Hindsight Is a Hermes Plugin"）用 Docusaurus SPA 提供，curl 抓回的是 0.6KB 空壳 + 600KB JS shell，肉眼读不到正文——**现代文档站越来越不 friendly to curl**，是 agent 抓取实践要面对的新边界。
